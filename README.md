# PD Room

Temporary maintenance page for PD Bot and PD Room.

This public repository contains only the static maintenance page. No application backend, Discord integrations, private user data, or credentials are included.

GitHub Pages publishes the main branch from the repository root. The known /bot/, /me/, /quests/ and /preview/ paths and the custom 404 page display the same maintenance notice. Each HTML file is self-contained and works without JavaScript or API requests.

Custom domain: pdroom.ru.
